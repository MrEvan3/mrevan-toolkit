# Código de Conduta e Ética de Uso

## 1. Nosso Compromisso
Queremos manter um ambiente acolhedor, respeitoso e focado no aprendizado para todos. Por isso, pedimos que todos os participantes, usuários e colaboradores do projeto **Mr Evan Intelligent Repair System** sigam este Código de Conduta, tanto nas interações da comunidade quanto no uso prático da ferramenta.

## 2. Propósito: Benefícios e Malefícios (Riscos)
Este projeto tem um caráter estritamente **educacional e profissional**. Ele foi criado para facilitar a vida de técnicos de TI, automatizando tarefas repetitivas.

* **Benefícios (O lado bom):** O script salva computadores corrompidos, devolve o desempenho para máquinas lentas, agiliza o diagnóstico de problemas críticos, permite suporte remoto rápido (AnyDesk) e ajuda usuários legítimos a recuperarem o acesso às suas próprias contas após esquecerem a senha.
* **Malefícios e Riscos (O lado perigoso):** Por ter acesso ao núcleo (kernel) e ao registro do sistema, o uso irresponsável desta ferramenta pode corromper o Windows, apagar arquivos necessários, causar telas azuis e desconfigurar redes. Além disso, as ferramentas de Recuperação Offline (como o bypass de senhas) podem ser usadas de forma maliciosa para acessar computadores de terceiros sem autorização.

## 3. Uso Ético e LGPD (Proteção de Dados)
O uso das ferramentas de backup (ex: Robocopy), acesso remoto e bypass de senhas deve estar em total conformidade com a **LGPD (Lei Geral de Proteção de Dados - Lei nº 13.709/2018)**.
* **O script em si NÃO coleta dados:** O código roda 100% localmente na máquina e não envia nenhuma informação, telemetria ou arquivo para servidores externos.
* **Responsabilidade do Técnico (Você):** Ao usar este script no computador de um cliente, VOCÊ é o responsável pelo tratamento dos dados. É terminantemente proibido usar as funções deste painel para bisbilhotar, copiar ou vazar arquivos pessoais, fotos, documentos ou senhas sem o consentimento explícito e formal do proprietário da máquina.
