# Code of Conduct

## Nosso compromisso

Queremos manter um ambiente acolhedor e respeitoso para todos. Por isso, pedimos que todos os participantes do projeto **Mr Evan Intelligent Repair System** sigam este Código de Conduta.

## Comportamento esperado

- Ser respeitoso com opiniões, experiências e origens diferentes
- Aceitar críticas construtivas
- Focar no que é melhor para a comunidade
- Mostrar empatia com outros membros

## Comportamento inaceitável

- Uso de linguagem ou imagens sexualizadas, assédio e comentários depreciativos
- Insultos ou ataques pessoais (trolling, comentários ofensivos)
- Assédio público ou privado
- Publicar informações privadas de outros sem consentimento
- Outras condutas que possam ser consideradas inadequadas em um ambiente profissional

## Aplicação

Os mantenedores do projeto têm o direito e a responsabilidade de remover, editar ou rejeitar comentários, commits, código e outras contribuições que não estejam alinhadas a este Código de Conduta.

## Contato

Se você presenciar ou for alvo de comportamento inaceitável, entre em contato com os mantenedores do repositório através das issues ou discussões do GitHub.

Este Código de Conduta é adaptado do [Contributor Covenant](https://www.contributor-covenant.org/), versão 2.0.
