# 🛠️ Mr Evan Intelligent Repair System (v2.1.0)

Console interativo avançado em PowerShell para manutenção preventiva, corretiva e otimização extrema do Windows (10 e 11). Desenvolvido por **Evandro Lemos**.

Transforme seu terminal em um verdadeiro canivete suíço para sysadmins, técnicos e power users!

## 🚀 Como executar

Abra o seu PowerShell **como Administrador** (obrigatório para a maioria das funções) e rode o comando abaixo:

```powershell
irm "[https://raw.githubusercontent.com/MrEvan3/mrevan-toolkit/main/MrEvanToolkit.ps1](https://raw.githubusercontent.com/MrEvan3/mrevan-toolkit/main/MrEvanToolkit.ps1)" | iex

Execute o PowerShell **como Administrador** para usar todas as funções.

## Funcionalidades

- **Otimizar agora** – Limpar lixo, cache e otimizar PC (faxina completa, rápida, navegadores, DNS).
- **Windows / Office** – Ativador via [Microsoft Activation Scripts (MAS)](https://github.com/massgravel/Microsoft-Activation-Scripts).
- **Ferramentas Gamer** – Reduzir latência (timer), prioridade alta, FSO, mouse 1:1, teclado, rede TCP, Game Bar/DVR, plano de energia.
- **Ferramentas do Sistema** – WinUtil, Windows Update, DNS, SFC/DISM, ponto de restauração, telemetria, CHKDSK, HOSTS, variáveis de ambiente, God Mode, ping, cache de fontes e mais.
- **Diagnóstico do PC** – Informações de hardware, disco, rede e atalhos para msinfo32, resmon, dxdiag.
- **Utilitários extras** – Limpeza de disco, armazenamento, Gerenciador de Tarefas, Programas e Recursos, Segurança do Windows, desempenho.

## Requisitos

- Windows 10 ou 11
- PowerShell 5.1 ou superior
- Execução como Administrador recomendada
